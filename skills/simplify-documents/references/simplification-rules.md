# 文档精简规则

处理政策、法律、合规、安全或高技术性文档，或目标输出比例低于 50% 时，阅读本规则。

## 内容优先级

| 优先级 | 内容                 | 处理方式                             |
| ------ | -------------------- | ------------------------------------ |
| 1      | 保护段落             | 逐字保留全部出现位置，并维持原文顺序 |
| 2      | 安全、法律和合规约束 | 保留完整效力、范围、例外和警告       |
| 3      | 事实、决定和操作步骤 | 保留理解内容或采取行动所需的全部信息 |
| 4      | 独特的解释性示例     | 删除后会使规则含糊时保留             |
| 5      | 背景和理由           | 除非用于支撑决定或避免误用，否则压缩 |
| 6      | 重复、客套和无效填充 | 优先删除                             |

## 安全与不安全的转换

安全转换必须保留相同的执行者、动作、对象、范围、条件、时间、确定性和约束强度。

| 通常安全                     | 通常不安全                 |
| ---------------------------- | -------------------------- |
| 合并完全重复的陈述           | 合并带有不同例外的相似陈述 |
| 将冗长目的短语改成直接表达   | 将“必须”改成“应该”         |
| 将并列段落转换为列表         | 重排相互依赖的操作步骤     |
| 删除解释同一规则的第二个示例 | 删除唯一的边界情况示例     |
| 为新手首次展开缩写           | 用宽泛词语替换精确技术术语 |
| 缩短引用表述但保留来源       | 将估计值表述为已确认事实   |

重点检查以下保真陷阱：

- **否定**：合并时容易丢失“不”“禁止”“除非”和“例外”；
- **范围**：“管理员”不能变成“用户”，“欧盟客户”不能变成“客户”；
- **量词**：“全部”“任意”“至少”“至多”和数值区间都是事实；
- **因果**：相关性或先后顺序不等于因果关系；
- **时间与版本**：当前、计划、弃用和历史状态不能互换；
- **示例**：除非原文明确说明，否则示例值不是默认值。

## 受众适配

| 受众     | 调整方式                               | 必须保留                         |
| -------- | -------------------------------------- | -------------------------------- |
| 管理者   | 优先呈现决定、影响、风险、负责人和期限 | 证据强度和重要限制               |
| 普通读者 | 使用常用词和简短定义                   | 必要领域术语和精确约束           |
| 操作人员 | 突出有序操作和可观察校验               | 命令、标签、前置条件、警告和回滚 |
| 专家     | 删除基础讲解并提高信息密度             | 精确术语、边界情况、数字和假设   |

不得通过改变实际义务、风险、资格或操作顺序来实现精简。

## 长度冲突

长度目标过于激进时，按以下顺序取舍：

1. 保留保护段落；
2. 保留约束和安全信息；
3. 保留事实和可执行步骤；
4. 保留正确理解所需的最小示例集合；
5. 压缩背景和理由；
6. 若仍无法达到目标，报告实际比例。

除非用户另行定义，百分比按以下方式计算：

```text
输出比例 = 精简后非空白字符数 / 原文非空白字符数
缩减比例 = 1 - 输出比例
```

例如，原文 1,000 个字符，输出 600 个字符，则输出比例为 60%，缩减比例为 40%。

## 简短示例

原文：

> 迁移前，操作人员必须创建备份。需要特别说明的是，迁移前必须创建备份。例如，测试环境可以使用夜间备份。生产环境必须使用迁移前两小时内创建的备份。

面向操作人员的保真精简：

> 迁移前创建备份。测试环境可使用夜间备份；生产环境必须使用此前两小时内创建的备份。

结果删除了重复内容，同时保留了操作、环境差异、约束强度和时间限制。
